## Purpose

Определить установленное поведение сессии Hyprland, запускаемые компоненты, настройки ввода, idle-политику и интеграцию shell с рабочей сессией.

## Requirements

### Requirement: Hyprland является основой compositor и сессии
Desktop-сессия MUST использовать Hyprland как compositor и MUST настраивать Wayland-окружение вокруг него.

#### Scenario: Запускается desktop-сессия
- **WHEN** запускается настроенная сессия Hyprland
- **THEN** сессия предоставляет compositor, ввод, управление окнами и интеграцию shell, ожидаемые рабочим окружением

### Requirement: При запуске сессии запускаются установленные desktop-сервисы
Конфигурация сессии MUST запускать shell проекта, polkit authentication agent, hypridle и hyprpaper как настроенные компоненты сессии.

#### Scenario: Hyprland завершает запуск
- **WHEN** сессия обрабатывает команды автозапуска
- **THEN** shell и настроенные вспомогательные компоненты сессии запускаются

### Requirement: Переменные окружения сессии идентифицируют Wayland desktop на Hyprland
Сессия MUST задавать настроенные идентификаторы desktop и переменную Wayland Qt platform, используемые текущей конфигурацией Hyprland.

#### Scenario: Desktop-приложение запускается внутри сессии
- **WHEN** приложение читает окружение сессии
- **THEN** оно получает настроенные идентификаторы desktop на Hyprland и настройку Qt platform для Wayland

### Requirement: Ввод сессии поддерживает установленные раскладки
Сессия MUST настраивать раскладки клавиатуры `us` и `ru` с переключением по Alt+Shift, а также natural scroll и tap-to-click для touchpad согласно текущей конфигурации.

#### Scenario: Пользователь переключает раскладку
- **WHEN** пользователь нажимает настроенную комбинацию переключения
- **THEN** Hyprland переключается между настроенными раскладками, а shell может отобразить активную раскладку

### Requirement: Сессия использует лёгкие визуальные настройки по умолчанию
Сессия MUST оставлять выключенными blur, shadows и animations и MUST использовать настроенные небольшие gaps и border size.

#### Scenario: Обычное окно отображается
- **WHEN** Hyprland применяет настройки оформления сессии
- **THEN** выключенные визуальные эффекты и animations не включаются

### Requirement: Idle-политика блокирует, выключает экран и переводит систему в suspend
Idle-конфигурация MUST блокировать сессию после настроенного периода бездействия, выключать питание дисплея после более длительного периода, включать питание дисплея при возобновлении и переводить систему в suspend после настроенного периода.

#### Scenario: Сессия остаётся бездействующей
- **WHEN** достигается каждый настроенный timeout hypridle
- **THEN** вызывается соответствующее действие блокировки, DPMS или suspend

### Requirement: Keybinds Hyprland предоставляют управление desktop и shell
Сессия MUST предоставлять настроенные keybinds для запуска основных приложений, управления окнами и рабочими пространствами, управления медиа/громкостью/яркостью, создания скриншотов и вызова IPC targets launcher, notifications, monitors и idle.

#### Scenario: Пользователь вызывает keybind shell
- **WHEN** нажимается настроенный keybind
- **THEN** Hyprland отправляет соответствующий IPC-вызов Quickshell для этой возможности
