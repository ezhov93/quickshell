## Purpose

Определить границы внешних зависимостей и установленное поведение установки конфигурации рабочего окружения.

## Requirements

### Requirement: Runtime-зависимости предоставляются дистрибутивом
Рабочее окружение MUST использовать пакеты дистрибутива для Hyprland, Quickshell, компонентов PipeWire, NetworkManager, UPower и других внешних платформенных компонентов, с которыми оно интегрируется.

#### Scenario: Проект устанавливается в целевой системе
- **WHEN** обязательный платформенный компонент отсутствует
- **THEN** deployment сообщает об отсутствующей зависимости, а не встраивает и не переimplementирует этот компонент

### Requirement: Предварительные условия runtime shell явно определены
Документация и проверки установки MUST указывать Quickshell версии 0.3.1 или новее с Networking, UPower, PipeWire и `Qt.labs.folderlistmodel`, Hyprland с `hyprctl` и настроенный Nerd Font как предварительные условия runtime.

#### Scenario: Обязательная runtime-зависимость отсутствует
- **WHEN** установщик проверяет систему
- **THEN** он сообщает пользователю об отсутствующем предварительном условии

### Requirement: Необязательные зависимости связаны с конкретными возможностями
Зависимости для управления яркостью, резервного определения сети и сетевых настроек, состояния батареи, применения обоев и других необязательных возможностей MUST оставаться связанными с использующими их возможностями.

#### Scenario: Пользователь не использует необязательную возможность
- **WHEN** соответствующая необязательная зависимость отсутствует
- **THEN** установщик сообщает о ней как об optional или capability-specific зависимости, а не считает её заменой core runtime shell

### Requirement: Установка выполняется от имени desktop-пользователя
Установщик MUST отклонять запуск от root и MUST устанавливать конфигурацию в `~/.config/quickshell` вызывающего пользователя.

#### Scenario: Установщик запущен с root-привилегиями
- **WHEN** эффективный пользователь — root
- **THEN** установка останавливается и пользователю предлагается запустить её без `sudo`

### Requirement: Существующая установка сохраняется перед заменой
Установщик MUST перемещать существующую целевую конфигурацию в backup-каталог перед установкой новой staged-конфигурации и MUST распознавать ситуацию, когда исходный каталог уже является целевым.

#### Scenario: Предыдущая конфигурация существует
- **WHEN** установка продолжается
- **THEN** предыдущая конфигурация сохраняется в backup до перемещения новой конфигурации на место

### Requirement: Deployment сохраняет структуру модулей shell
Установщик MUST копировать QML-файлы и `qmldir`, сохраняя относительную структуру каталогов, и MUST NOT запускать shell или изменять настройки Hyprland во время установки.

#### Scenario: Установка завершается
- **WHEN** staged-конфигурация перемещается в целевой каталог
- **THEN** установленные файлы сохраняют структуру исходных модулей, а пользователь получает отдельную команду для запуска Quickshell

### Requirement: Логика зависимостей для разных дистрибутивов изолирована
Проект MUST хранить различия пакетов и deployment для Arch и Debian в выделенных слоях зависимостей или установки, а не распределять проверки дистрибутива по shell, сервисам или UI.

#### Scenario: Название пакета отличается между целевыми дистрибутивами
- **WHEN** добавляются или изменяются зависимости
- **THEN** соответствующее отображение меняется в слое пакетов или deployment
