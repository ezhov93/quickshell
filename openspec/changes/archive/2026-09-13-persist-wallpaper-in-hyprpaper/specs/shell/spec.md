## MODIFIED Requirements

### Requirement: Выбранные обои сохраняются

Оболочка MUST сканировать настроенные каталоги, предоставлять выбор и предпросмотр обоев, применять выбранное изображение через настроенный поставщик обоев и записывать путь только после успешного применения. Успешно применённый путь MUST сохраняться в пользовательской конфигурации `hyprpaper.conf` как запись wallpaper для монитора. При следующем запуске поставщик `hyprpaper` MUST читать эту запись и самостоятельно восстанавливать изображение; оболочка читает путь только для отображения текущего состояния и не должна повторно применять его через IPC. Ошибка применения и ошибка записи MUST различаться. Legacy-файл `~/.config/quickshell/wallpaper.conf` MUST NOT читаться.

#### Scenario: Обои успешно применены

- **WHEN** внешняя команда применения завершилась успешно
- **THEN** выбранный путь становится текущим и оболочка запрашивает атомарное сохранение записи в `~/.config/hypr/hyprpaper.conf`
- **AND** остальные параметры пользовательского `hyprpaper.conf` сохраняются

#### Scenario: Применить обои не удалось

- **WHEN** внешняя команда применения завершилась ошибкой
- **THEN** выбранный путь не записывается как успешно применённый, а ошибка доступна для диагностики

#### Scenario: Применение успешно, но запись не удалась

- **WHEN** запись пути завершается ошибкой после успешного применения
- **THEN** сообщается ошибка сохранения; уже применённое изображение не объявляется автоматически отменённым

#### Scenario: При запуске shell существует сохранённый wallpaper

- **WHEN** `hyprpaper.conf` содержит непустую запись wallpaper для доступного монитора
- **THEN** поставщик обоев запускается с этой записью без необходимости отдельного `wallpaper.conf`
- **AND** содержимое старого `~/.config/quickshell/wallpaper.conf` игнорируется
- **AND** оболочка не выполняет отложенную повторную команду применения через IPC
