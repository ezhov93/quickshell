## ADDED Requirements

### Requirement: Сетевые настройки nmtui открываются отдельным плавающим окном

При запуске сетевых настроек из оболочки примерный профиль сессии MUST позволять Hyprland однозначно отличить окно `nmtui` от обычных окон выбранного терминала и MUST переводить только это окно в floating-режим. Команда запуска MUST отключать внутренний отступ Foot только для этого экземпляра. Обычные окна того же терминала MUST сохранять стандартное размещение и глобальные настройки Foot. Успешный запуск зависит от наличия терминала, `nmtui` и применённого пользователем профиля Hyprland.

#### Scenario: Пользователь открывает сетевые настройки из панели

- **WHEN** оболочка запускает доступные терминал и `nmtui` в сессии с применённым примерным профилем
- **THEN** созданное для `nmtui` окно имеет выделяемый идентификатор и Hyprland размещает его как floating-окно

#### Scenario: Пользователь открывает обычный терминал

- **WHEN** в той же сессии запускается обычное окно выбранного терминала без идентификатора сетевых настроек
- **THEN** правило `nmtui` к нему не применяется и его стандартный режим размещения не изменяется

#### Scenario: Пользователь открывает nmtui без внутренних полей Foot

- **WHEN** оболочка запускает `nmtui` с глобальной настройкой Foot `pad=25x25`
- **THEN** для этого экземпляра применяется локальное переопределение `main.pad=0x0`, а глобальный отступ обычных терминалов не изменяется

#### Scenario: Внешняя команда недоступна

- **WHEN** терминал или `nmtui` отсутствует либо не запускается
- **THEN** оболочка не выдаёт открытие floating-окна за успешное, а существующий путь сообщения об ошибке запуска остаётся доступен

### Requirement: Размер окна изменяется перетаскиванием за границу

Примерный профиль Hyprland MUST разрешать изменение размера окна мышью за его границу. Для плавающих окон профиль MUST включать прилипание к другим окнам и краям монитора с порогами 4 и 5 пикселей соответственно и MUST учитывать настроенные внутренние отступы между окнами.

#### Scenario: Пользователь изменяет размер плавающего окна

- **WHEN** пользователь наводит указатель на границу плавающего окна и перетаскивает её
- **THEN** Hyprland изменяет размер окна в соответствии с движением указателя

#### Scenario: Пользователь перемещает плавающее окно рядом с другим окном

- **WHEN** расстояние между плавающим окном и другим окном достигает настроенного порога
- **THEN** Hyprland выравнивает окно с учётом `gaps_in`

#### Scenario: Пользователь перемещает плавающее окно к краю монитора

- **WHEN** расстояние между окном и краем монитора достигает настроенного порога
- **THEN** Hyprland притягивает окно к краю монитора
