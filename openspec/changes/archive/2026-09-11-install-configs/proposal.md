## Why

После переноса конфигураций в `configs/` текущий `install.sh` устанавливает только Quickshell и оставляет системные настройки без воспроизводимого deployment-пути. Нужно разворачивать весь конфигурационный слой в пользовательский XDG-каталог, не затрагивая чужие файлы и живую графическую сессию.

## What Changes

- Расширить установщик: копировать содержимое всей `configs/` в `~/.config/`, сохраняя относительные пути.
- Для текущего набора устанавливать `configs/hypr/*` в `~/.config/hypr/*`; будущие подпапки `configs/` должны обрабатываться тем же общим механизмом.
- Перед заменой управляемых целевых подпапок создавать backup с понятным путём и восстанавливать его при ошибке установки.
- Не заменять весь `~/.config`, не использовать `sudo`, не устанавливать пакеты и не запускать/reload-ить Hyprland или Quickshell.
- Обновить документацию, карту статуса и ручной checklist установки.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `system-package-management`: расширить контракт текущего установщика с QML-only deployment до безопасной установки проектной папки `configs/` в пользовательский XDG config directory.

## Impact

Затрагиваются `install.sh`, `configs/`, документация и delta-спека установки. Появляется запись в `~/.config/` с backup управляемых подпапок; package manager, systemd units, live session и runtime shell не запускаются установщиком.
