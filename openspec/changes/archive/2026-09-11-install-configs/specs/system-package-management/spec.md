## MODIFIED Requirements

### Requirement: Установка выполняется от имени desktop-пользователя

Текущий установщик MUST отклонять запуск от root и устанавливать оболочку и проектные конфигурации в XDG-каталоги вызывающего пользователя: `~/.config/quickshell` и соответствующие пути из `configs/` под `~/.config/`. Поддержка другого XDG-пути установки не входит в текущий контракт.

#### Scenario: Установщик запущен с root-привилегиями

- **WHEN** эффективный идентификатор пользователя равен нулю
- **THEN** установщик завершает работу до изменения целевых каталогов и предлагает запуск без `sudo`

### Requirement: Существующая установка сохраняется перед заменой

Перед заменой существующего целевого каталога или ссылки установщик MUST переместить прежний управляемый объект в отдельный резервный путь и сообщить этот путь пользователю. Управляемыми объектами являются `~/.config/quickshell` и целевые подпапки, соответствующие содержимому `configs/`; весь `~/.config` MUST оставаться нетронутым. Если исходный каталог уже является целевым, установщик MUST завершиться без повторного развёртывания. Резервная копия не означает автоматического переноса пользовательского состояния в новую установку.

#### Scenario: Предыдущая конфигурация существует

- **WHEN** подготовленные файлы готовы к установке и управляемый целевой путь уже существует
- **THEN** прежний объект перемещается в резервный путь до установки новой версии, а пользователь получает расположение резервной копии

#### Scenario: Источник совпадает с целевой конфигурацией

- **WHEN** установщик обнаруживает, что запущен из целевого каталога
- **THEN** он сообщает, что конфигурация уже установлена, и не создаёт новую резервную копию

### Requirement: Deployment сохраняет структуру модулей shell

Установщик MUST копировать QML-файлы и `qmldir`, сохраняя их относительные пути, а также все обычные файлы из `configs/` в соответствующие пути под `~/.config/`. Установка MUST NOT запускать оболочку, применять/reload-ить Hyprland, разворачивать пакеты или изменять живую конфигурацию сессии. Область копирования MUST NOT включать перенос произвольных файлов пользовательского состояния из прежней установки.

#### Scenario: Установка завершается

- **WHEN** подготовленные runtime-файлы и конфигурации перемещаются в целевые каталоги
- **THEN** QML, `qmldir` и файлы `configs/` сохраняют относительную структуру, а пользователь получает отдельные команды для запуска или применения

#### Scenario: Ошибка при установке конфигураций

- **WHEN** копирование или перемещение одного из управляемых путей завершается ошибкой
- **THEN** установщик сообщает ошибку и пытается восстановить соответствующие backup без запуска графической сессии
