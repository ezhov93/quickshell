## Why

Сейчас нажатие на сетевой индикатор запускает `nmtui` внутри отдельного окна Foot. Такой интерфейс плохо вписывается в оболочку, требует внешнего терминала и не показывает состояние доступных Wi‑Fi сетей непосредственно пользователю. Нужен лёгкий popover в стиле системного меню macOS, использующий уже доступный API `Quickshell.Networking`.

## What Changes

- Заменить запуск `nmtui` из сетевого индикатора на popover, привязанный к кнопке Network в Bar.
- Добавить переключатель Wi‑Fi в верхней части popover.
- Разделить сети на «Сохранённые сети» и «Другие сети» по признаку `known`.
- Показать текущую сеть, состояние подключения, уровень сигнала и тип защиты.
- Поддержать подключение к сохранённым открытым и PSK-сетям, а для новых защищённых сетей — ввод пароля в отдельном модальном диалоге.
- Сделать раздел «Другие сети» сворачиваемым и автоматически обновлять его из модели NetworkManager, включая сканирование только пока popover открыт.
- Оставить пункт «Другие настройки», запускающий `nmtui` для VPN, Enterprise Wi‑Fi и операций, которые не покрывает popover.
- Сохранить текущий статус Ethernet в сетевом индикаторе; управление Ethernet не входит в первую версию popover.
- Удалить из обычного пути запуска зависимость от команды `foot -e nmtui`, но сохранить `nmtui` как ручной расширенный fallback.
- Не добавлять подключение к скрытым сетям в рамках этого изменения.

## Capabilities

### New Capabilities

Нет. Change расширяет существующую сетевую возможность оболочки.

### Modified Capabilities

- `shell`: сетевой индикатор вместо запуска терминального `nmtui` предоставляет Wi‑Fi popover с управлением и fallback на расширенные настройки.
- `session`: профиль больше не обязан описывать floating-окно для штатного открытия сетевых настроек; ручной пункт `nmtui` остаётся внешним fallback.

## Impact

- `shell/modules/Bar/services/NetworkService.qml` — состояние Wi‑Fi, сканирование, подключение, ошибки и операции NetworkManager.
- `shell/modules/Bar/components/NetworkWidget.qml` и новые компоненты popover/password view — UI и локальное состояние взаимодействия.
- `shell/config/Config.qml` — команда расширенных сетевых настроек и связанные подписи при необходимости.
- `shell/modules/Bar/components/qmldir`, документация, checklist и `openspec/specs/shell/spec.md`.
- Используется существующий `Quickshell.Networking`; новый демон, polling вне активного popover и отдельный сетевой процесс не добавляются.
- Профиль Hyprland больше не требует отдельного floating-правила для обычного открытия сетевых настроек; ручной `nmtui` остаётся внешней операцией пользователя.
