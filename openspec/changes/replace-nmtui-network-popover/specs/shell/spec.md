## MODIFIED Requirements

### Requirement: Панель предоставляет состояние и управление рабочим столом

Панель MUST отображаться на доступных экранах и предоставлять рабочие пространства, активное окно, трей, медиа, громкость, яркость, ресурсы, сеть, батарею при её наличии, раскладку и время. Неизвестные значения CPU и температуры MUST отображаться как `N/A`, а при отсутствии доступной батареи её индикатор MUST быть скрыт. Сетевой индикатор MUST открывать встроенный Wi‑Fi popover, а не запускать терминал для обычных сетевых действий. Эти условия предполагают доступность обязательных QML-импортов.

#### Scenario: Панель отображается в многомониторной сессии

- **WHEN** оболочке доступны несколько экранов
- **THEN** на каждом доступном экране отображается панель

#### Scenario: Нет доступной батареи

- **WHEN** поставщик состояния батареи не предоставляет присутствующую батарею ноутбука
- **THEN** панель не показывает индикатор батареи с вымышленным зарядом

#### Scenario: Измерение ресурса недоступно

- **WHEN** значение CPU или температуры неизвестно
- **THEN** соответствующее значение отображается как `N/A`, а не как подтверждённый ноль

#### Scenario: Пользователь открывает сетевой popover

- **WHEN** пользователь нажимает или активирует с клавиатуры сетевой индикатор
- **THEN** оболочка открывает popover рядом с индикатором, показывает состояние Wi‑Fi и не запускает терминал автоматически

#### Scenario: Список сетей разделён по сохранённости

- **WHEN** сетевой popover открыт и поставщик Wi‑Fi предоставляет найденные сети
- **THEN** известные сети отображаются в разделе «Сохранённые сети», неизвестные — в разделе «Другие сети», а текущая сеть отмечена как подключённая

#### Scenario: Другие сети обновляются автоматически

- **WHEN** popover открыт и поставщик Wi‑Fi обновляет найденные сети
- **THEN** оболочка автоматически обновляет сворачиваемый раздел «Другие сети» без отдельной кнопки обновления и прекращает собственное сканирование после закрытия popover

#### Scenario: Пользователь подключается к сети

- **WHEN** пользователь выбирает сохранённую открытую или PSK-защищённую сеть
- **THEN** оболочка запрашивает подключение, показывает переходное состояние и сообщает об ошибке, если подключение не удалось

#### Scenario: Пользователь подключается к новой защищённой сети

- **WHEN** пользователь выбирает неизвестную PSK-защищённую сеть
- **THEN** popover показывает отдельный модальный диалог пароля, не отображает пароль открытым текстом и начинает подключение только после подтверждения пользователем

#### Scenario: Скрытая сеть не предлагается встроенным popover

- **WHEN** пользователь просматривает доступные сетевые действия
- **THEN** встроенный popover не предлагает ручной ввод SSID скрытой сети, а расширенные операции остаются доступны через «Другие настройки»

#### Scenario: Пользователь открывает расширенные настройки

- **WHEN** пользователь выбирает пункт «Другие настройки»
- **THEN** оболочка запускает доступный внешний `nmtui` как расширенный fallback для VPN, Enterprise Wi‑Fi и неподдерживаемых операций

#### Scenario: Wi‑Fi недоступен

- **WHEN** Wi‑Fi аппаратно выключен, отсутствует или поставщик NetworkManager недоступен
- **THEN** popover показывает безопасное состояние и доступную диагностику, не выдавая пустой список за успешное сканирование
