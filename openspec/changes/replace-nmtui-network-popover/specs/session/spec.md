## MODIFIED Requirements

### Requirement: Сетевые настройки nmtui открываются отдельным плавающим окном

Штатные сетевые действия из оболочки MUST выполняться во встроенном popover с переключателем Wi‑Fi, разделами сохранённых и других сетей, обновлением сканирования и подключением поддерживаемых открытых и PSK-сетей. Профиль сессии MUST NOT требовать отдельного floating-правила для штатного popover. Оболочка MUST сохранять доступный пункт запуска `nmtui` для расширенных настроек, но успешность этого fallback зависит от наличия терминала, `nmtui` и применённого пользователем профиля Hyprland.

#### Scenario: Пользователь открывает сетевые настройки из панели

- **WHEN** пользователь активирует сетевой индикатор в панели
- **THEN** отображается встроенный popover, а отдельное окно терминала для штатного сценария не создаётся

#### Scenario: Пользователь открывает обычный терминал

- **WHEN** пользователь открывает обычный терминал без выбора расширенных сетевых настроек
- **THEN** профиль не обязан применять к нему специальное floating-правило сетевого интерфейса или изменять его стандартные отступы

#### Scenario: Пользователь открывает nmtui без внутренних полей Foot

- **WHEN** пользователь выбирает пункт `nmtui` в popover
- **THEN** оболочка запрашивает запуск внешнего терминала с `nmtui` как отдельной расширенной операцией

#### Scenario: Внешняя команда недоступна

- **WHEN** терминал или `nmtui` отсутствует либо не запускается
- **THEN** оболочка не выдаёт запуск расширенных настроек за успешный и оставляет доступным сообщение об ошибке
