# Документация LPDE

Начинай с документа, соответствующего задаче. Не нужно загружать все материалы для каждого небольшого изменения.

| Задача | Читать |
|---|---|
| Понять продукт и текущий этап | [Контекст проекта](project-context.md) |
| Изменить структуру, интеграцию, данные или процессы | [Архитектура](architecture.md), затем относящийся [ADR](adr/) |
| Узнать действующее требование | [Основные OpenSpec-спеки](../openspec/specs/) |
| Проверить, реализовано ли требование | [Карта статуса](spec-status.md) |
| Спланировать и применить изменение | [Работа с OpenSpec](openspec-workflow.md) |
| Выбрать проверки | [Стратегия тестирования](testing.md) |
| Понять возможные следующие этапы | [Дорожная карта](roadmap.md) |

Основные capability:

- [desktop-environment](../openspec/specs/desktop-environment/spec.md) — границы продукта и текущей поставки;
- [architecture](../openspec/specs/architecture/spec.md) — сквозные архитектурные ограничения;
- [shell](../openspec/specs/shell/spec.md) — пользовательские возможности оболочки;
- [system-package-management](../openspec/specs/system-package-management/spec.md) — зависимости и текущая установка;
- [session](../openspec/specs/session/spec.md) — декларации примерного профиля сессии.

Принятые решения:

- [ADR-0001: LPDE является продуктом](adr/0001-de-product-boundary.md);
- [ADR-0002: модульная оболочка Quickshell](adr/0002-modular-quickshell-shell.md).

[Архитектурный разбор от 10 сентября 2026 года](architecture-review.md) сохранён как историческая памятка. Он объясняет происхождение изменений, но действующими источниками являются контекст, архитектура, принятые ADR и OpenSpec.

Корневой [PLANS.md](../PLANS.md) содержит прежнюю идею TuneD, а roadmap — этапы развития. Ни один из них сам по себе не является активным заданием. Разрешённая работа находится в явной задаче пользователя и выбранном OpenSpec change.

При противоречии между требованием и кодом используй [правила репозитория](../AGENTS.md): назови конфликт, не выбирай источник молча и не расширяй scope без решения.
